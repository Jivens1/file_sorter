\#  Automated File Sorter



A Python script that automatically organizes messy folders by sorting files into categorized subfolders (Images, Documents, Music, etc.).



\##  Features



\- Automatically detects file types by extension

\- Moves files into organized folders

\- Skips folders (safe to run)

\- Customizable - add your own file types



\##  Usage



1\. Open `file\_sorter.py`

2\. Change the `folder\_path` variable to your target folder

3\. Run: `python file\_sorter.py`



\##  Supported File Types



| Category | Extensions |

|----------|------------|

| Images | `.jpg`, `.png`, `.gif` |

| Documents | `.pdf`, `.docx`, `.txt` |

| Music | `.mp3`, `.wav` |

| Presentations | `.pptx` |
